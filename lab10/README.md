# Лабораторна 10. Unity: бюджет текстур

Бюджет відеопам'яті на текстури: 24 МБ. Платформа: Android, формат ASTC.
Пам'ять рахується за формулою `ширина × висота × біт на піксель / 8`, з міпмапами ще × 4/3.
Код калькулятора: [`lab10_budget.py`](lab10_budget.py).

## Результат

| | Було | Стало |
|---|---|---|
| За розрахунком (12 текстур сцени) | 156,00 МБ | 17,86 МБ |
| За профайлером (рядок Textures) | 479,6 МБ (1084 текстури) | 285,4 МБ (1130 текстур) |

Бюджет 24 МБ дотримано із запасом 6,14 МБ. Економія за розрахунком: 138,14 МБ.

## Налаштування в Unity

Усі зміни зроблено на вкладці Android з увімкненим Override For Android.
Нормалям виставлено Texture Type = Normal map. Прапорець sRGB вимкнено для UI_Atlas і Noise,
для кольорових текстур він увімкнений.

## Профайлер

Розділ Memory, рядок Textures.

До: 1084 текстури, 479,6 МБ.

Після: 1130 текстур, 285,4 МБ.

## Спостереження

Цегляна стіна (Building_Albedo): на швах з'явилися квадрати або плями після застосування ASTC 6×6.
Це типовий випадок для блокового стиснення: на різких межах між цеглою й швом у один блок потрапляє
кілька відтінків одразу, і формат вже не передає їх точно.
